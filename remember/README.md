# 我记得 · Claude Code 版

以赵雷《我记得》为背景音乐的 86 秒动画，规格为 1920×1080、30fps。

- **故事**：这首歌唱的是轮回，一个人带着前世的记忆来到这一世，又认出了前世的那个人。动画里，橙色的 Clawd 是记得一切的那一个，粉色、戴蝴蝶结的 Clawd 是它每一世都会遇见的人。前世它是大人，她是小孩；这一世她成了妈妈，它是她怀里的婴儿。
- **不放进仓库的文件**：歌曲来自用户上传的文件，受版权保护。歌曲和成片都不放进仓库，`remember/build/` 已加入忽略列表。
- **不使用歌词**：画面上不出现歌词，字幕是原创的旁白短句。`analyze.py` 用 Whisper 只取每句唱词的起止时间，不保存歌词。

| 文件 | 作用 |
| --- | --- |
| `analyze.py` | 分析音乐：拟合节拍网格，检测低频击打，导出 30fps 的低、中、高频包络，并用 Whisper 测出每句唱词的起点 |
| `src/beatmap.js` | `analyze.py` 的输出，是画面唯一的节奏依据 |
| `src/timeline.js` | 分镜时间和原创字幕 |
| `src/chars.js` | 两个 Clawd 角色和道具：旧皮箱、枣子、铜钱、襁褓、草帽、瓜皮帽 |
| `src/visuals.js` | Canvas 画面，每个镜头一个函数 |
| `render.mjs` | 用 Playwright 逐帧渲染，再用 ffmpeg 合成；最后检查成片音轨是否和原曲对齐 |

## 上传片段的分析结果

- 时长 85.88 秒，139.94 BPM，第一拍在 0.016 秒。片段从第一段主歌开始，1.1 秒就进人声，在副歌中途截止，结尾加 1.2 秒淡出。
- 1.1–26.6 秒是主歌，低频一直在；26.6–36 秒和 40–56 秒低频（贝斯和底鼓）基本撤出；56 秒进副歌，低频能量一下涨到原来的五倍左右。
- 每句唱词的起点：1.1、4.28、5.98、7.68、9.62、14.86、17.92、19.68、21.4、23.52、28.16、33.94、37.12、41.98、47.48、51.02、55.66、59.18、60.84、64.64、69.48、72.02、74.64、78.44、83.66 秒。镜头都切在这些点上。

## 重新渲染

```bash
cd remember
pip install librosa imageio-ffmpeg faster-whisper
python3 analyze.py /path/to/我记得.mp3   # -> build/bgm.wav、src/beatmap.js（beatmap.js 已提交，可以跳过这一步）
node render.mjs /path/to/我记得.mp3      # -> build/remember.mp4，并检查音轨对齐
node render.mjs --stills 2.5,18.6,62.5   # 抽帧检查，输出到 build/stills/
```
