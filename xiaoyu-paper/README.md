# 小宇 · 纸片 MV

张震岳《小宇》的另一个版本：分镜和 `xiaoyu/` 的像素版相同，画风换成彩纸剪贴。时长 3 分 44 秒，规格为 1920×1080、30fps，字幕是你提供的歌词。

- **纸片画法**：每一块形状都像从彩纸上剪下来的，边缘带一点手剪的起伏，下面有一层柔和的投影，整帧再叠一层纸纤维纹理和暗角。画面直接画在 1920×1080 的画布上（镜头内部用 960×540 的坐标）。
- **角色**：两个原创纸偶。男孩是棕色乱发、黄 T 恤（胸前一朵小云）、牛仔裤、红球鞋；女孩是黑色长发、白花、浅蓝连衣裙。头、身体、上臂、前臂、腿都是分开的纸片，靠关节角度摆姿势。男孩会变成一朵带棕色头发的纸云，和一只帆上贴着红心、船身上有他脸的折纸小船。
- **字幕**：写在一条撕下来的纸条上，边上贴着一小段胶带。每个字依次落下，唱到哪里就从灰色染成红色（夜景里是蓝色）。进度来自 Whisper 测出的每个字的起点（只存时间，不存文字）。
- **字体**：霞鹜文楷（LXGW WenKai，OFL）的子集，改名为 Xiaoyu Paper，许可见 `assets/OFL.txt`。
- **不放进仓库的文件**：歌曲、歌词和成片只放在 `xiaoyu-paper/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `src/beatmap.js` | 节拍和逐字时间，与 `xiaoyu/` 相同（由 `analyze.py` 生成） |
| `src/timeline.js` | 分镜表，与 `xiaoyu/` 相同 |
| `src/paper.js` | 纸片工具：带投影的剪纸形状、纸纹、两个纸偶、纸条字幕 |
| `src/scenes.js` | 35 个镜头函数，海边小镇、纸云、折纸船、灯塔等道具，以及逐帧合成（镜头之间淡入淡出） |
| `render.mjs` | 用 Playwright 逐帧渲染，用 ffmpeg 合成音乐，最后检查音轨是否对齐 |

分镜见 `xiaoyu/README.md`。

## 重新渲染

```bash
cd xiaoyu-paper
node render.mjs /path/to/小宇.mp3 --lyrics 你的歌词.lrc          # -> build/小宇_纸片MV.mp4，约 15 分钟
node render.mjs --stills 20,70.5,134 --lyrics 你的歌词.lrc       # 抽帧检查，输出到 build/stills/
node render.mjs /path/to/小宇.mp3 --lyrics 你的歌词.lrc --from 140 --to 150   # 只渲染一段预览
```
