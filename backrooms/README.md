# 后室 · Level 0

成片：[`build/backrooms.mp4`](build/backrooms.mp4)，规格为 1920×1080、30fps、H.264 + AAC，时长 41.5 秒。

一支 1996 年摄像机拍下的 found footage：有人在一片望不到头的黄色办公室里一路走，每次回头，身后那个东西都离得更近。最后灯灭了，再亮起来时，它只是一只小小的 Clawd，嘴里说着“哼！别关灯”。

画面、音乐和音效全部由 JavaScript 生成：画面是自己写的软件光线投射器，声音由 Web Audio 合成，没有使用任何模型、图片、录音或采样。

## 分镜

| 时间 | 内容 |
| --- | --- |
| 0–3s | 黑场淡入，摄像机“嘟”一声开始录像，日光灯嗡嗡作响，偶尔闪一下 |
| 3–14s | 第一人称慢慢往前走，穿过一间间一模一样的黄色房间，标题“LEVEL 0 · 后室 · 大厅” |
| 14–26s | 每次灯闪过后，镜头猛地回头一瞥：走廊尽头站着一个又高又黑的东西。它在 9 格外、7 格外、5 格外、3.6 格外…… |
| 26–33s | 开始奔跑，镜头剧烈晃动，呼吸声急促，第五次回头时它已经在 2.6 格外 |
| 33–35s | 死路。镜头慢慢转过身，尖啸声越来越高，日光灯炸灭 |
| 35–36s | 摄像机切到夜视模式，在一片死寂里，只有两只发白的眼睛和心跳声 |
| 36–38s | 灯猛地亮起：站在那里的是一只小小的橙色 Clawd，气鼓鼓地说“哼！”“别关灯” |
| 38–41.5s | 录像停止，黑底白字：“THE BACKROOMS · LEVEL 0 / 后室没有出口。/ 但总有人替你留着灯。”，八音盒轻轻收尾 |

## 怎么做的

| 文件 | 作用 |
| --- | --- |
| `src/world.js` | **唯一的时间轴**：32×20 的地图、摄像机路线、走路与奔跑的速度、每一次灯闪、每一次回头、身后那个东西的位置，以及由走过的距离算出的每一步脚步声 |
| `src/render.js` | 光线投射器：程序生成的壁纸、潮湿地毯和天花板，日光灯有的会坏、会闪，距离越远越黄越雾。再加上摄像机效果：红蓝色偏、扫描线、噪点、跟踪抖动条、辉光、夜视模式和屏幕上的 REC / 日期 / 时间码 |
| `src/audio.js` | 合成声音：随灯光忽强忽弱的日光灯嗡嗡声、潮湿地毯上的脚步、奔跑时的喘息、每次回头的低频冲击、灯灭前不断升高的尖啸、心跳声，以及结尾的八音盒 |
| `subset.py` | 把 `src/` 里用到的汉字从站酷快乐体（SIL OFL）里抠出来，生成字体子集 |
| `render.mjs` | 用 Playwright 逐帧渲染，再由 ffmpeg 合成 MP4 |

**脚步声为什么能踩准？** 镜头每走过 0.6 格就是一步，脚步声、镜头上下晃动和身后那个东西的位置都是同一份“走过的距离”算出来的，所以画面和声音不会漂移。

```bash
cd backrooms
python3 subset.py ZCOOLKuaiLe-Regular.ttf   # 只有改了汉字才需要
node render.mjs                             # -> build/backrooms.mp4，约 7 分钟
node render.mjs --stills 4.8,14.5,35.3      # 导出单帧，便于检查
node render.mjs --audio-only                # 只重做声音，再合进现有的视频
```

也可以直接在浏览器里打开 `index.html`，点“▶ 播放”，页面会先实时合成声音再开始播放。
