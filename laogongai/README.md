# 老公爱 · 像素 MV

以《老公爱》为背景音乐的 2 分 09 秒像素动画 MV，字幕是你提供的 37 句歌词，规格为 1920×1080、30fps。

- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。工具函数从 `aicuo/` 复制而来，换了角色，另写了这首歌自己的道具。
- **角色**：都是原创。"他"是穿紫色大号卫衣、宽松浅蓝牛仔裤、白球鞋、戴金链子的说唱少年，耍酷时戴上墨镜；"她"是黑长发挑染粉色、粉色短外套、别黄色发卡的女孩。另有两个兄弟、一个灰头发的路人和一个金发的新邂逅。
- **片头**：黑暗里一颗像素心在跳，第一个鼓点（0.6 秒）上霓虹城市亮起来、烟花炸开，"老 公 爱"三个粉色大字一拍一个砸下来，四周乱弹聊天气泡（messed it around）；唱到 see through your lies 时片名挪到上面，他戴上墨镜，一道扫描光照穿她的"老公我爱你♥"，气泡翻成闪烁的 LIES。
- **一句一镜**：前两句在片头里，其余每句歌词一个镜头，切点就是 `.lrc` 里这句的时间：拍立得化成像素灰、手机上弹钢琴、楼顶分一副耳机、天平上两堆"谎"、雨夜路口和地图、删短信、开启勿扰出门遇见新的人、T 台上的 Baggy jeans、兄弟们、派对上甩掉想她的念头、压下来的黑夜和发烫的心、拉住手、上锁的回忆胶片、日历和破门而入的她、抽屉里的信、胸口的烙印、传不到她耳朵里的声音、关掉 AUTO-TUNE 和迷宫一样的心、揉了一地的情书、焦虑的心电图、失控的跑车、FLEX、硬币雨里逃离、探照灯找遍整座城市、她瞧都不瞧路人、戳她气鼓鼓的脸、打碟台上的 DROP、跑车 pull up、寺庙前 PERFECT 连击、水深火热里的玻璃心、走出墙后、飞蛾扑火、舞台和台下鼓掌的她、火辣的 HOT、擦不掉他的大橡皮。
- **片尾**：最后一句后面 15 秒的空档是楼顶看烟花，片名在夜空里亮起来，最后收成 THE END。
- **字幕**：逐字浮上来，按估计的演唱进度从米白变成粉色，下面一颗小粉心跟着进度往右走。
- **跟着音乐动**：用 ffmpeg 解码音乐，动态规划跟踪节拍。片名砸下来、震屏、心跳、打击垫、音箱、DROP 的冲击波都踩在拍子上。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `laogongai/build/`，这个目录已加入忽略列表。渲染时用 `--lyrics` 读入你自己的 `.lrc`；片名固定写在 `props.title_str()` 里，不读 `.lrc` 的 `[ti:]`。

| 文件 | 作用 |
| --- | --- |
| `pix.py` | 像素工具：缓动、点阵渐变与光晕、粒子、城市与花草、角色精灵（含墨镜、金链子、宽腿裤）、文字 |
| `props.py` | 通用道具：节拍、点阵贴图、镜头内分段、震屏、烟、片名大字、拍立得、特写的大脸 |
| `motifs.py` | 从 `aicuo/` 原样复制，这里用到会裂开的大心、风的白线和闪电 |
| `kit.py` | 这首歌自己的道具：霓虹字和霓虹城、房间、手机和聊天气泡、手指、钢琴键和音符、信封、天平和"谎"砖、红绿灯、跑车、音箱和打碟台、立麦、寺庙、火苗和飞蛾、故障效果、字幕下的小粉心 |
| `sc_a.py` | 片头和第一段主歌（0–35.9 秒） |
| `sc_b.py` | 预副歌和第二段前半（35.9–68.0 秒） |
| `sc_c.py` | 第二段说唱（68.0–94.3 秒） |
| `sc_d.py` | 最后一段和片尾（94.3 秒–结束） |
| `scenes.py` | 分镜表：每句歌词对应哪个镜头、用什么转场 |
| `render.py` | 读歌词、分析音乐、排镜头、转场和字幕、分块并行编码、合成音乐；`--vertical` 输出 1080×1920 竖屏版 |

## 重新渲染

```bash
cd laogongai
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py /path/to/老公爱.mp3 --lyrics 你的歌词.lrc                     # -> build/老公爱_像素MV.mp4
python3 render.py /path/to/老公爱.mp3 --lyrics 你的歌词.lrc --stills 1,20,60   # 抽帧检查，输出到 build/stills/
python3 render.py /path/to/老公爱.mp3 --lyrics 你的歌词.lrc --range 0,20       # 只渲染一段带声音的预览
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐。4 核机器上整首大约 75 秒。
