# 几分之几 · 像素 MV

以卢广仲《几分之几》为背景音乐的 3 分 43 秒像素动画 MV，字幕用你提供的歌词，规格为 1920×1080（16:9）、30fps。

- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。天空、光晕、半透明和溶解都用 Bayer 点阵过渡。工具函数从 `aicuo/` 复制而来，换了角色。
- **质感**（`fx.py`）：
  - 角色按镜头里主光的方向做三档点阵明暗，迎光一侧的轮廓换成边缘光（夕阳里是金色，月光下是淡蓝）；特写的胸像、她的侧脸、大球鞋和手也一样。
  - 天上有被落日照亮边缘的积云和薄云，太阳两边有远山，地平线上有一层薄雾，光源射出慢慢转的光束。
  - 平原是一笔一笔的麦穗和田垄，房间有墙纸、护墙板、地毯、串灯、窗外照进来的光和浮尘。
  - 画面角落有离镜头很近、失焦的麦子、草叶和树叶，地上有贴地的影子，空气里飘着浮尘、花粉和萤火。
  - 每一帧最后加泛光（亮处往外渗光，用点阵分档）、阴影偏紫的分离色调和暗角；放大到 1080p 以后每 4 行最后一行稍暗，像扫描线，再叠一层固定的细颗粒，像隔着一块旧屏幕看。
- **角色**：都是原创。"他"是黑色短发、穿天蓝 T 恤的年轻人，老了以后是灰白头发、棕色开衫、拄拐杖；"她"是黑褐色长发、芥末黄连衣裙、珊瑚色发卡，脚上一双全白的球鞋（歌里唱的"踩着全白球鞋"）。
- **片头**：黑暗的方格纸上，一个像素像光标一样随拍子闪，拉成一道横线；四面八方飞来的小方块在横线上下各拼出一个"几"，成了一个分数"几分之几"。横线一直拉到画面两边变成地平线：上面亮起黎明，下面铺开金色的平原，太阳从横线后面升起，两个"几"挪上天空，中间落下"分""之"，拼成横排的片名，再被风吹散成金色的小点。
- **贯穿全片的母题**：
  - 压着平原的大太阳：地平线在太阳底下被压得往下凹。第一句、最后一句和片尾都回到这片平原。
  - 八块拼成的心：像切饼一样分成八块，旁边用分数记着"几分之几"。第一段副歌她递给他第一块（1/8 → 3/8）；第二段副歌一张张拍立得飞进来，每一块都换成前面镜头里的回忆（3/8 → 7/8）；她离开以后，这些回忆一块块褪成旧照片的颜色，落回他胸口。最后一块始终空着，直到桥段里碎掉的天明在他手心里聚成那一块。
- **一句一镜**：每句唱词一个镜头，切点就是 `.lrc` 里这句的时间；两段副歌的同一句各用一套不同的画面。片头从 0 秒演到第一句，最后一句后面的空档用作片尾。
- **字幕**：逐字浮上来，按估计的演唱进度从米白变成阳光金；下面一条点线小路，一只白球鞋跟着进度一步一步往右走。唱完后字幕只多停两秒。
- **跟着音乐动**：用 ffmpeg 解码音乐，动态规划跟踪节拍（约 72 BPM）。光标的闪烁、拼图块落位、分数跳动、掌机世界里的跳跃、流星、天明照片碎掉的那一下都踩在拍子上。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `jifen/build/`，这个目录已加入忽略列表。渲染时用 `--lyrics` 读入你自己的 `.lrc`。

## 重新渲染

```bash
cd jifen
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py /path/to/几分之几.mp3 --lyrics 你的歌词.lrc                     # -> build/几分之几_像素MV.mp4
python3 render.py /path/to/几分之几.mp3 --lyrics 你的歌词.lrc --stills 3,60,140   # 抽帧检查，输出到 build/stills/
python3 render.py /path/to/几分之几.mp3 --lyrics 你的歌词.lrc --range 0,20        # 只渲染一段带声音的预览
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐。用 `--jobs` 可以改进程数。抽帧时加 `--full` 输出带扫描线和颗粒的 1920×1080 原尺寸画面。
