# 几分之几 · 像素 MV

以卢广仲《几分之几》为背景音乐的 3 分 46 秒像素动画 MV，带跟唱字幕，规格为 1920×1080、30fps。

- **像素画法**：所有画面都画在 480×270 的画布上，只用整像素的方块，渐变用 4×4 拜耳抖动。导出时由 ffmpeg 用最近邻放大 4 倍，每个像素都是清晰的 4×4 方块。
- **故事**：橙色的 Clawd 是"我"，粉色、戴蝴蝶结、穿白球鞋的 Clawd 是"你"。歌里唱"你成为了我的几分之几"，所以左上角有一个分成八块的小圆饼，每多一段回忆，就有一块变成粉色。最后是 5/8：她离开以后，那几块还留在他身上。
- **字幕**：每句唱词对应一行字幕，时间来自 Whisper 测出的每个字的起点。字幕像游戏对话框一样先逐字打出，再随演唱进度从左到右变亮。字幕旁的 ♪ 随拍子跳动。
- **不放进仓库的文件**：歌曲来自用户上传的文件，受版权保护。歌曲、成片和歌词文件都不放进仓库，`fraction/build/` 已加入忽略列表。
- **不使用歌词**：仓库里不保存歌词，默认字幕是原创的短句，按唱词的时间显示。如果你有自己的歌词文件（.lrc），可以用 `--lyrics` 让字幕显示你提供的内容，见下文。

| 文件 | 作用 |
| --- | --- |
| `analyze.py` | 分析音乐：拟合节拍网格（144 BPM），检测底鼓，导出 30fps 频段包络，并用 Whisper 测出每句唱词和每个字的起点（只存时间，不存文字） |
| `src/beatmap.js` | `analyze.py` 的输出 |
| `src/timeline.js` | 分镜时间、原创字幕、饼图每一块变粉的时刻 |
| `src/pixel.js` | 像素工具：抖动渐变、像素图形、Clawd 角色、像素字、跟唱字幕框、饼图、抖动转场 |
| `src/scenes.js` | 15 个镜头，每个镜头一个函数 |
| `render.mjs` | 用 Playwright 逐帧渲染 480×270 的画面，用 ffmpeg 最近邻放大到 1920×1080 并合成音乐，最后检查音轨是否对齐 |
| `assets/fraction-pixel-subset.woff2` | 像素字体：Fusion Pixel 12px Proportional SC 的子集，按 OFL 要求改名为 Fraction Pixel。许可见 `assets/OFL.txt` |

## 音乐分析结果

- 时长 226.32 秒，144 BPM，第一拍在 0.304 秒。每句唱词大约 16 拍（6.7 秒）。
- 0–16 秒前奏；16.3 秒进人声；38–42 秒几乎静音停顿，42 秒鼓进来；68.5 秒第一段副歌；97.7–123 秒一串短句；123 秒第二段副歌；150 秒唱"离开"；163–186 秒桥段，全曲能量最高；186–214 秒最后一段；214 秒后是尾奏。
- Whisper 在纯音乐的前奏里会凭空"听"出一句，在 180 秒的长音上也会，这两段的字词置信度很低（0.60 和 0.26），按 0.65 的阈值丢掉。最后一共保留 26 句。

## 重新渲染

```bash
cd fraction
pip install librosa imageio-ffmpeg faster-whisper
python3 analyze.py /path/to/几分之几.mp3                    # -> build/bgm.wav、src/beatmap.js（beatmap.js 已提交，可以跳过）
node render.mjs /path/to/几分之几.mp3                       # -> build/fraction.mp4，用原创字幕
node render.mjs /path/to/几分之几.mp3 --lyrics 你的歌词.lrc  # 字幕改用你自己的 .lrc 文件
node render.mjs --stills 20,70.5,134                       # 抽帧检查，输出到 build/stills/
```

`.lrc` 的格式是每行 `[分:秒.百分秒]字幕`，例如 `[01:08.50]……`。高亮的进度仍然按 Whisper 测出的字的时间走。注意每行要短于 30 个字左右，否则会超出画面宽度。
