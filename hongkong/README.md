# 香港夜雨 · Hong Kong Night Rain（像素透视错觉动画）

成片：[`build/hongkong_night.mp4`](build/hongkong_night.mp4)，规格为 1920×1080（16:9）、30fps、H.264 + AAC，时长 50 秒。

画面先在 640×360 的像素网格上渲染，再用最近邻放大 3 倍到 1080p，所以每个像素都是清晰的 3×3 方块。

## 用到的 skill

本片按照 [simcraft 的 perspective-illusion skill](https://github.com/dotslashsimran/simcraft/blob/main/skills/video/perspective-illusion/SKILL.md) 制作，以 `scramble_night.html` 模板的引擎为基础，保留了下面这些部分：

- **相机**：相机始终保持水平、不倾斜。所有参数都走同一条 Fritsch-Carlson 单调三次曲线，`W` 和 `fov` 在对数空间里插值。镜头之间用 dolly zoom 过渡，即主体框住的宽度不变，镜头焦段变化。
- **望远镜头压平**：用约 2° 的望远镜头从 1.3 km 外拍摄，整条街被压成一面霓虹招牌墙，两侧的路灯也会重叠成一根。
- **转角镜头**：每个转角镜头先用 4° 长焦拍，画面看起来是平的，然后焦段拉宽，空间才打开成 3D。
- **暗中换位**：四辆红色的士只在画面最平的时候移动纵深。镜头静止时它们横排并列在路口，镜头再打开时已经变成一条斜线（换位发生在 18.2–20.6 秒和 45.4–46.6 秒）。
- **插画渲染**：分四个通道渲染，包括颜色、法线和深度、平涂色、阴影遮罩，再合成墨线和两色调明暗。夜景部分加了湿地面的屏幕空间反射、雨点涟漪、辉光、锚定在世界空间里的雾霭，以及夜色调色。
- **循环**：画面中的动画（雨、行人、电车、屏幕广告、航空灯闪烁、霓虹故障闪烁）都是时间的纯函数，每个循环正好走整数周期。行人和电车统一在 26.6 秒换位，这是全片最快的一次运镜（从路口升上天台），用 `window.probe` 测得。

在模板之外新增的内容：

- **像素通道**：先按 1280×720 渲染，每 2×2 个像素取平均。叠加像素字体标题后，用 4×4 Bayer 有序抖动吸附到固定的 48 色夜景调色板，得到 640×360 的画面。
- **招牌图集**：约 160 块招牌（霓虹灯箱、悬挑招牌、铺头招牌、天台招牌）的字面全部画进一张 4096² 的画布，合成一个网格，只用一次绘制调用。少数霓虹灯会按整数周期“故障闪烁”。
- **软件渲染优化**：这个环境没有 GPU，WebGL 由 SwiftShader 软件渲染，因此做了几项优化。阴影图每个子帧只更新一次；去掉 MSAA，改用 2 倍超采样加抖动来抗锯齿；行人、的士和电车都烘焙成少量网格，行人使用顶点色。

## 场景

这是一条九龙风格的购物街，沿 -z 方向延伸：

- **街道**：中间铺双线电车轨，两侧各一条行车线，路口画了黄格（box junction）、斑马线和“望右 LOOK RIGHT”。
- **两侧唐楼**：外墙是马赛克砖，窗户装有铁窗花，外墙挂着冷气机和晾衫竹，天台有水箱、铁皮屋和天线，其中一栋搭着竹棚和绿色防护网。
- **招牌**：有悬挑的霓虹招牌、当铺“押”字招牌、铺头灯箱和天台大招牌。
- **路口两侧的转角楼**：右边一栋挂着 LED 大屏，广告在“雨夜特賣”和“叮叮”之间切换。
- **街尾**：“東方大酒樓”的天台霓虹，远处是一片高楼和一座有塔冠的地标塔。天空有起伏的山脊线、被城市灯光映成粉紫色的低云，还有一轮月亮。
- **街上的活动**：双层电车（叮叮）、红色的士、红顶小巴、撑伞的行人、报纸档、大排档、巴士站、交通灯和行人栏杆。

所有店名和品牌都是虚构的，角色也都是原创。

## 分镜（50 秒）

| 时间 | 镜头 |
| --- | --- |
| 0–2.6s | 望远镜头：整条街压成一面霓虹墙，片名「香港夜雨」出现 |
| 2.6–7.2s | dolly zoom 下降到膝盖高度，从湿漉漉的电车轨上仰望招牌，电车驶来（叮叮） |
| 7.2–15.6s | 右侧转角：先用长焦拍得平平的，再展开成 3D，看清路口、的士和人潮 |
| 15.6–20.6s | 回到望远镜头，的士在这时暗中换位 |
| 20.6–25.4s | 升到路口上空，的士已经排成一条斜线 |
| 25.4–30.6s | 镜头升上天台：水箱、招牌顶和远处的天际线 |
| 30.6–39.0s | 左侧转角：先平后 3D，俯视黄格路口和斑马线 |
| 39.0–43.0s | 低机位沿街望去，第二辆电车经过 |
| 43.0–50s | 回到望远镜头，的士换回原位，片尾字幕「晚安，香港」 |

## 声音

`music.py` 用 numpy/scipy 纯合成生成原创配乐和环境声，不用任何采样或录音。

- **配乐**：72 BPM 的 lo-fi 夜曲，和弦进行是 Dm9–G13sus–Cmaj9–Am9，用电钢琴、贝斯、鼓刷和颤音琴演奏。
- **环境声**：雨声、檐下滴水、霓虹变压器的嗡嗡声、轮胎压过积水的声音、远处的雷声，还有两次电车的“叮叮”声。
- **对画面的节奏点**：电车铃声配合镜头里出现电车的时刻。26.7 秒镜头升上天台时，编曲进入完整段落。

## 重新生成

```bash
cd hongkong
npm install                       # three + Noto Serif TC
pip install numpy scipy
python3 music.py                  # -> build/music.wav
node render.mjs --stills=1,6,15,28.2,41.4          # 检查静帧 -> build/stills/
node render.mjs --preview --query="?scale=.5"       # 半分辨率快速预览 -> build/preview.mp4
node render.mjs                   # 成片 -> build/hongkong_night.mp4（软件渲染约 1 小时）
```

可以直接在浏览器中打开 `scene.html?zoom=2` 查看场景（需要在 `hongkong/` 目录下起一个静态服务器）。调用 `window.render(ms)` 可以跳到任意时刻。
