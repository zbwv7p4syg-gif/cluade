# 富士山下 · Claude Code 版

以陈奕迅《富士山下》为背景音乐的 54 秒动画，规格为 1920×1080、30fps。

- **角色**：他是橙色的 Clawd，她是粉色、戴蝴蝶结的 Clawd。
- **不放进仓库的文件**：歌曲来自用户上传的文件，受版权保护。歌曲和成片都不放进仓库，`fuji/build/` 已加入忽略列表。
- **不使用歌词**：画面上不出现歌词，字幕是原创的旁白短句。

## 上传片段的分析结果

分析方法：用 librosa 做能量和节奏分析，用 Whisper large-v3 识别粤语人声。识别结果只用来确定每句唱词的时间，不保存歌词。

- 时长 54.13 秒：0–22 秒是前奏，22.25–53.9 秒是第一段主歌，片段在主歌结束处截止。
- 这首抒情歌没有明显的鼓点，适合跟着乐句切换画面。主歌每句的起点分别在 22.25、26.53、30.75、35.90、40.48、44.76、49.60 秒，大约每 4.3 秒一句。
- 画面在每句开始时用 0.45 秒的叠化转场；前奏也按同样的 4.3 秒间隔分镜。车里雨刷的摆动和路灯光扫过的节奏，是每句的四分之一。
