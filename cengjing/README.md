# 曾经是情侣 · 像素 MV

以《曾经是情侣》为背景音乐的 3 分 02 秒像素动画 MV，字幕是你提供的歌词，规格为 1920×1080、30fps。

- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。天空、光晕、半透明和溶解都用 Bayer 点阵过渡。工具函数从 `zuozhuandeng/pix.py` 复制而来，换了角色造型，另加了一套特写用的大脸（24×22 的字符画，五官按表情现画）。
- **角色**：两个原创角色。"他"是黑色短发、穿牛仔蓝衬衫的男孩；"她"是黑褐色长发、穿珊瑚红连衣裙、别一枚红发卡的女孩。多年以后的样子：他穿深色外套、围红围巾，她把长发盘了起来。
- **主线**：红线。片头一根红线在黑暗里勾出一颗心；相遇时红线系上两人的小指；岔路口两人分头走，红线越拉越长；分离时红线绷断；最后断掉的一截顺着河漂走。字幕下面也有一根跟着演唱进度往右长的红线，线头是一颗小心。
- **一句一镜**：每一句唱词都有自己的镜头，切点就是 `.lrc` 里这句的时间，重复的句子也各换一套画面。最后一句之后超过 5 秒没有歌词的地方用作片尾。镜头顺序是按这首歌的 36 句写的，换别的歌词会循环使用。
- **"一样"的三句**：用左右分屏，左边是那时候的她（旧照片的颜色），右边是现在的她，做着一样的事；第三句两张笑脸合成一个。
- **跟着音乐动**：用 ffmpeg 解码音乐，动态规划跟踪节拍（约 54 BPM），再按和声变化定出小节线。片头的心在拍点上描完、跳动、裂开；闪电、锄地、换装、撞墙、烟花、锁扣、花瓣掉落都踩在拍子上。
- **字幕**：文泉驿点阵正黑 16px，逐字从点阵里浮出来，再按估计的演唱进度从左到右由白变成粉红。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `cengjing/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `pix.py` | 像素工具：缓动、点阵渐变与光晕、粒子、城市与花草、两个角色的精灵图、文字 |
| `props.py` | 道具：红线、雨伞、纸船、风筝、孔明灯、玫瑰、云朵片名、特写大脸、拍立得、旧照片和录像带的调色 |
| `sc_a.py` | 片头和第一段主歌：黄昏山坡、风、裂开的天空、雨、溪流和大河 |
| `sc_b.py` | 第二段主歌：四季轮转、发光的花田、三组分屏、路和岔口、风雪、无尽的路、小星球、站台、沙漏 |
| `sc_c.py` | 第一段副歌：倒带、相遇、红线绷断、擦肩而过、换装、狂奔、撞墙、同心锁、胶片、沉入深水、枯萎的玫瑰、碎掉的合照、雨停在半空 |
| `sc_d.py` | 第二段副歌和片尾：楼顶烟花、褪色的合照、八音盒、天亮的码头、孔明灯、心形灯、河的两岸、片名重现 |
| `scenes.py` | 分镜表：每句歌词对应哪个镜头、用什么转场 |
| `render.py` | 读歌词、分析音乐、排镜头、转场和字幕、分块并行编码、合成音乐 |

## 重新渲染

```bash
cd cengjing
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py /path/to/曾经是情侣.mp3 --lyrics 你的歌词.lrc                      # -> build/曾经是情侣_像素MV.mp4
python3 render.py /path/to/曾经是情侣.mp3 --lyrics 你的歌词.lrc --stills 8,67,105    # 抽帧检查，输出到 build/stills/
python3 render.py /path/to/曾经是情侣.mp3 --lyrics 你的歌词.lrc --range 0,20         # 只渲染一段带声音的预览
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐。用 `--jobs` 可以改进程数。
