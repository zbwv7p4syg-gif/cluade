# 小宇 · 8-bit 像素 MV

以张震岳《小宇》为背景音乐的 3 分 44 秒像素动画 MV，字幕是你提供的歌词，规格为 1280×720、24fps。和 `xiaoyu/`（像素版）、`xiaoyu-paper/`（剪纸版）是同一首歌的另一个版本：像素更粗，更像老游戏机的画面。整部片子只有一个 Python 文件。

- **像素画法**：所有画面用 Pillow 画在 320×180 的画布上，导出时用最近邻放大 4 倍。镜头之间用 Bayer 点阵溶解过渡。
- **角色**：两个原创角色，都是 8×14 像素的精灵图。"我"是黑发、穿蓝 T 恤的男孩；"你"是棕色长发、穿红裙子的女孩。另外还有一朵会眨眼的小云和一只小木船。
- **一句一镜**：每一句唱词都有自己的镜头，切点就是 `.lrc` 里这句的时间。空行后面如果超过 5 秒没有歌词，就分别用作间奏和片尾。镜头顺序是按这首歌的 32 句写的，换别的歌词会循环使用。
- **字幕**：Unifont 像素字体，放在游戏对话框里。先逐字打出，再按这一句的时长从左到右变黄。变黄的进度是按时长估算的，没有逐字对齐。
- **跟着音乐动**：用 ffmpeg 解码音乐，算出每一帧的音量和 32 段频谱，用在角色跳动、心跳和间奏的频谱条上。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `xiaoyu-8bit/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `render.py` | 全部代码：精灵图和绘图工具，32 个唱词镜头加片头、间奏、片尾，对话框字幕，音频分析，分块并行编码，合成音乐 |

## 重新渲染

```bash
cd xiaoyu-8bit
apt install ffmpeg fonts-unifont   # 需要 ffmpeg 和 Unifont 字体
pip install pillow numpy
python3 render.py /path/to/小宇.mp3 --lyrics 你的歌词.lrc                      # -> build/小宇_8bit_MV.mp4
python3 render.py /path/to/小宇.mp3 --lyrics 你的歌词.lrc --stills 20,75,140   # 抽帧检查，输出到 build/stills/
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐，在 4 核机器上大约 45 秒。用 `--jobs` 可以改进程数。
