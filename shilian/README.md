# 永不失联的爱 · 像素 MV

以《永不失联的爱》为背景音乐的 4 分 26 秒像素动画 MV。字幕用的是你提供的歌词，规格为 1920×1080、30fps。

- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。天空、光晕、银河和溶解都用 Bayer 点阵过渡。工具函数从 `aicuo/` 复制而来，角色换了造型。
- **角色**：都是原创。"他"穿暖橙色连帽卫衣，像傍晚的太阳；"她"披深棕色长发，穿天蓝毛衣，别一枚黄色星星发卡。
- **主线是"信号"**：开头手机没有信号，"亲爱的，你在哪？"一直显示未送达。副歌里，两座楼顶之间的传声筒线两头都有了人，线上跑着一颗颗小心。分开以后他在电话亭里一遍遍打给她，直到收到"我还在"。间奏里一颗心穿过云层、卫星和月亮，飞到她的窗前，显示"已送达"。结尾两人牵着手走在天亮的楼顶上，状态栏显示"已连接"。
- **片头**：黑暗里，手机在搜索信号。屏幕发出一圈信号波，照亮夜里的两座楼顶：他拿着传声筒，线的那头却没有人。线上的小心飘上天空，镜头跟着往上摇进银河，满天星星聚成片名。星星鲸鱼从片名后面游过。片名在小节线上化成流星雨落下，接上第一句。
- **一句一镜**：每句唱词一个镜头，切点就是 `.lrc` 里这句的时间。两处"你是我"分别是她的特写和他的特写；四处"这一辈子都不想失联的爱"分别是楼顶的传声筒、卫星连着的两个房间、心形的灯塔光和一颗小星球。"呜"和"啊啊啊啊"接着间奏演成一段太空旅程；"oh oh"之后两人并肩坐在弯月上，呼应开头她一个人坐在月亮上发呆。
- **字幕**：逐字浮上来，按估计的演唱进度从米白变成信号青。字幕下面拉出一根线，一颗小心跟着进度跑过去，跑过的地方会亮起来。唱完以后字幕只多停两秒。
- **跟着音乐动**：用 ffmpeg 解码音乐，再用动态规划跟踪节拍（约 85 BPM）并定出小节线。片名在小节线上拼好、落下，心跳、烟花、聊天气泡和心电图都踩在拍子上。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `shilian/build/` 里，这个目录已经加进忽略列表。渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `pix.py` | 像素工具：缓动、点阵渐变与光晕、粒子、城市与花草、角色精灵、文字 |
| `props.py` | 通用道具：节拍、点阵贴图、镜头内分段、震屏、烟、钟、片名大字、特写的大脸、雨和倒影 |
| `motifs.py` | 从 `aicuo/` 带过来的道具：大心、纸飞机、长椅、灯塔、极光、相册 |
| `sig.py` | 这首歌自己的道具：信号格、手机和聊天气泡、传声筒和发光的线、心电图、纸船、星星鲸鱼、卫星、小星球、天台、电话亭、日历、各种形状的云、牵着的手、地球、山 |
| `kit.py` | 常用布景：夜空和银河、弯月、流星雨、躺着/斜着/站在星球上的人、花田、摩天轮、想法云、伞 |
| `sc_a.py` | 片头和第一段主歌：手机、楼顶、星星片名、月亮上的她、乱麻、怪物影子、灰色人群、形状各异的云、落地的小云、绕路灯、靠肩膀 |
| `sc_b.py` | 第一段副歌和间奏：大心、传声筒、星辰大海、故事书和印章、红线和星座、她的特写、卫星、松开的手、电话亭、"我还在"、太空旅程 |
| `sc_c.py` | 第二段主歌：流星天台、四季窗、灰伞人群、游乐园回忆、同一个月亮、人海、回头、一直都在 |
| `sc_d.py` | 第二段副歌、尾声和片尾：来电、心形灯塔、心跳聊天、花田拥抱、地球顶上、他的特写、小星球、千山、银河下的山顶、月亮上、天亮、片尾 |
| `scenes.py` | 分镜表：每句歌词对应哪个镜头、用什么转场 |
| `render.py` | 读歌词、分析音乐、排镜头、转场和字幕、分块并行编码、合成音乐；`--vertical` 输出 1080×1920 竖屏版 |

## 重新渲染

```bash
cd shilian
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py /path/to/永不失联的爱.mp3 --lyrics 你的歌词.lrc                     # -> build/永不失联的爱_像素MV.mp4
python3 render.py /path/to/永不失联的爱.mp3 --lyrics 你的歌词.lrc --stills 3,60,140   # 抽帧检查，输出到 build/stills/
python3 render.py /path/to/永不失联的爱.mp3 --lyrics 你的歌词.lrc --range 0,20        # 只渲染一段带声音的预览
python3 render.py /path/to/永不失联的爱.mp3 --lyrics 你的歌词.lrc --vertical          # -> build/永不失联的爱_像素MV_竖屏.mp4
```

默认用 4 个进程，每个进程渲染一段连续的帧。最后不重新编码，直接把这几段拼起来，再合上音乐。用 `--jobs` 可以改进程数。
