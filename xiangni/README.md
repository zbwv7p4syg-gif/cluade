# 想你和我们以后 · 像素 MV

以苏运莹《想你和我们以后》为背景音乐的 4 分 24 秒像素动画 MV，字幕是你提供的歌词，规格为 1920×1080、30fps。

- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。天空、光晕、半透明和镜头之间的溶解都用 Bayer 点阵过渡。
- **角色**：两个原创角色，头部是 12×12 的字符画，身体按姿势现画，最后自动描一圈深色轮廓。"我"是棕色头发、别着小太阳发夹、穿黄衣服、爱笑的女孩；"你"是黑色乱发、穿蓝衣服、有点忧郁的男孩。两人各有少年、上班、老年三套造型。片头那颗左黄右蓝的心会在后面反复出现。
- **一句一镜**：每一句唱词都有自己的镜头，切点就是 `.lrc` 里这句的时间。空行后面超过 5 秒没有歌词的地方，依次用作间奏、空档和片尾；间奏是四个镜头，从间奏里第一个小节线开始按小节平分。镜头顺序是按这首歌的 27 句写的，换别的歌词会循环使用。
- **跟着音乐动**：用 ffmpeg 解码音乐，算出每一帧的音量；用动态规划跟踪节拍，再按和声变化最大的相位定出小节线。片头按前奏的小节线剪（0.63 秒第一个和弦，之后每小节约 3.9 秒），间奏的烟花在拍点上炸开，灯和心跟着拍子跳。
- **字幕**：文泉驿点阵正黑 16px，逐字从下面弹上来，这一句结束前 0.3 秒用点阵淡出；只有一两个字的长音会轻轻起伏。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `xiangni/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `pix.py` | 像素工具：缓动、点阵渐变与光晕、粒子和烟花、城市与花草、两个角色的精灵图、文字 |
| `scenes.py` | 片头、27 个唱词镜头、四个间奏镜头、空档和片尾 |
| `render.py` | 读歌词、分析音乐、排镜头、转场和字幕、分块并行编码、合成音乐 |
| `cover.py` | 竖屏封面：两人站在两边楼顶，红线在大月亮前绕成一颗心，系着两人的小指。沿用 MV 的角色、片名字体和画法，画在 270×480 的画布上，放大 4 倍到 1080×1920 |

## 重新渲染

```bash
cd xiangni
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py /path/to/想你和我们以后.mp3 --lyrics 你的歌词.lrc                      # -> build/想你和我们以后_像素MV.mp4
python3 render.py /path/to/想你和我们以后.mp3 --lyrics 你的歌词.lrc --stills 20,75,140   # 抽帧检查，输出到 build/stills/
python3 render.py /path/to/想你和我们以后.mp3 --lyrics 你的歌词.lrc --range 0,20         # 只渲染一段带声音的预览
python3 cover.py --lyrics 你的歌词.lrc                                                   # -> build/想你和我们以后_封面.png，1080×1920 竖屏封面
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐，在 4 核机器上大约两分半钟。用 `--jobs` 可以改进程数。
