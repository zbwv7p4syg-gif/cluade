# 九分之九 · 像素 MV

以用户上传的《九分之九》（卢广仲）为背景音乐的 3 分 46 秒像素动画 MV。规格为 1920×1080、30fps，字幕来自用户自己的 .lrc 文件。

- **故事**：一个男孩和一只狗的十五年。九岁那年，他在三合院领回一只黄色小狗，它的四只脚是白的，正好对上"金色的侧脸踩着全白球鞋"。那天他在写九九乘法表，小狗一脚踩在"九九八十一"上，于是它就叫**九九**。后来九九在公车站等他放学回家，陪他看稻田里倒映的星空，跟他一起搬进城市。十五岁那年的一个夜里，它走进一扇光做的门，回到了当年那片平原。
- **贯穿全片的"九"**：他房间里有一扇九宫格窗。每唱一次"九分之九"，窗格就跟着唱词一格一格亮起来，九格对应九个音节。另外还有九九九岁生日的九根蜡烛、缺最后一块的九片拼图，以及最后由九块地板光斑变成的九段回忆。
- **时间用狗的年龄来记**：左上角是一块骨头形状的名牌，写着"九九 · 两个月"、"九九 · 6岁"……一直到"九九 · 15岁"。
- **和《几分之几》MV 的区别**：仓库里的 `fraction/` 用的是同一段录音，讲的是 Clawd 的爱情故事，左上角有一块慢慢变粉的饼图。这一版换成了人物和狗的像素画、另一个故事，也换成了另一套"九"的母题，没有沿用那一版的镜头和字幕样式。
- **像素画法**：所有画面都画在 384×216 的画布上，只用整像素的方块，透明和渐变都用 4×4 拜耳抖动。导出时由 ffmpeg 用最近邻放大 5 倍，每个像素都是清晰的 5×5 方块。近景镜头用"2 倍镜头"：画面照常画好，再把其中 192×108 的区域放大成整帧。这类镜头里的灯光改用分层的色带，不再用抖动，避免放大后出现粗糙的网点。
- **字幕**：渲染时读取用户的 .lrc。逐字落下，"九分之九"四个字是金色。每唱一拍，字幕下方就多出一个小爪印，像九九跟着歌词往前走。用户提供的歌词只到 2:59，3:06–3:34 还有四句唱词，这一段只有画面，没有字幕。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，放在 `nine/build/`，这个目录已加入忽略列表。

| 文件 | 作用 |
| --- | --- |
| `analyze.py` | 分析音乐：拟合节拍网格（144 BPM），检测底鼓，输出 `src/beatmap.js` |
| `make_font.py` | 从 Fusion Pixel 生成像素字体子集 `assets/nine-pixel.woff2`，包含 ASCII、常用标点和 3755 个一级汉字，按 OFL 要求改名为 Nine Pixel |
| `src/timeline.js` | 25 个镜头的起止时间、狗年龄名牌，以及三句"九分之九"的音节时间 |
| `src/pixel.js` | 像素工具：形状、抖动渐变、色带光、像素字、字幕（爪印）、骨头名牌 |
| `src/chars.js` | 角色：男孩（小孩、少年、青年三个年龄）和九九（幼犬、成犬、老狗），由部件拼成后统一描边 |
| `src/scenery.js` | 布景：天空、平原稻田、红砖三合院、榕树、九宫格窗、房间、城市 |
| `src/scenes.js` | 镜头调度：抖动转场、2 倍镜头、名牌和字幕叠加 |
| `src/act1.js` / `act2.js` / `act3.js` | 三幕的镜头，每个镜头一个函数 |
| `render.mjs` | 用多个 Playwright 页面并行逐帧渲染，再用 ffmpeg 最近邻放大并合成音乐，最后检查音轨是否对齐 |

## 音乐分析结果

这首歌和 `fraction/` 用的是同一段录音：时长 226.32 秒，144 BPM，第一拍在 0.304 秒，42.06 秒鼓进来。三句"九分之九"里每个音节的起点（只有时间，没有歌词），取自 `fraction/analyze.py` 用 Whisper 测出的结果：

- 75.04 秒起的九个音节：九宫格窗一格一格亮起
- 130.04 秒起的九个音节：九根蜡烛一根一根点亮
- 156.66 秒起的九个音节：雨夜里九格窗玻璃依次浮现九个回忆的图标

## 重新渲染

```bash
cd nine
pip install librosa                                            # analyze.py 需要；make_font.py 另外需要 fonttools brotli
python3 analyze.py /path/to/九分之九.mp3                        # -> build/bgm.wav、src/beatmap.js（beatmap.js 已提交，可以跳过）
node render.mjs /path/to/九分之九.mp3 --lyrics 你的歌词.lrc     # -> build/nine.mp4
node render.mjs --sheet 20,70.5,134                            # 抽帧拼成一张检查图：build/stills/sheet.png
node render.mjs --stills 20,70.5                               # 1920×1080 单帧：build/stills/
```

`.lrc` 的格式是每行 `[分:秒.百分秒]字幕`，用空行标记一句结束。不加 `--lyrics` 时，会沿用 `build/lyrics.js` 里上一次的字幕。
