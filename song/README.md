# Claude 听见了音乐

一段以 Clawd（Claude Code 的吉祥物）为主角、配合用户上传音乐制作的 13.8 秒动画，规格为 1920×1080、**60fps**。

画面全部由音乐分析结果驱动。上传的音乐和成片**不放进仓库**（`song/build/` 已加入 `.gitignore`），需要时用下面的命令在本地重新生成。

| 文件 | 作用 |
| --- | --- |
| `analyze.py` | 分析音乐：拟合固定节拍网格（140.08 BPM）；以约 3ms 的精度检测低频（底鼓/808）和中频（军鼓、拍手、打击乐）的每一次击打；计算每次击打的亮度；导出 60fps 的低、中、高频包络 |
| `src/beatmap.js` | `analyze.py` 的输出，是画面唯一的节奏依据 |
| `src/visuals.js` | Canvas 画面 |
| `src/clawd.js` | Clawd 角色（戴耳机） |
| `render.mjs` | 用 Playwright 以 60fps 逐帧渲染，再用 ffmpeg 合成；最后把成片音频解码出来，与原曲做互相关，确认音轨逐样本对齐 |

```bash
cd song
python3 analyze.py /path/to/music.mov   # -> build/bgm.wav, src/beatmap.js
node render.mjs                         # -> build/claude_song.mp4
```

## 音乐分析结果

- 140.08 BPM，速度恒定，第一拍在 0.054 秒，整段正好 8 小节（每小节 1.713 秒）。
- 第 0–3 小节：低频稀疏，底鼓和 808 断断续续，中频每个八分音符都有打击。
- 6.44 秒：贝斯提前一拍进入（弱起）。
- 第 4–6 小节（6.9–12.05 秒）：贝斯持续铺满，是最满的段落。
- 第 7 小节（12.05 秒起）：贝斯在强拍上撤出，只剩中高频。

## 画面如何跟着音乐走

| 时间 | 音乐 | 画面 |
| --- | --- | --- |
| 0–3.5s | 前奏 | 暗房间，Clawd 戴耳机闭眼听歌，每拍点一次头。每一次低频击打点亮一块舞池地砖，每一次中频击打从耳机里弹出一个发光方块（越亮的声音飞得越高）。字幕“♪ Claude 正在听……” |
| 3.5–6.4s | 渐入 | 背后的均衡器墙随真实频段能量升起。Clawd 开始随拍左右摇摆。字幕“它开始跟着节奏动了” |
| 6.0–6.9s | 弱起 | 最后一拍蹲下蓄力，在贝斯进来的瞬间起跳并空翻，同时出现“来了！” |
| 6.9s | 进入主段 | 强拍上闪白、硬切画面 |
| 6.9–8.6s | 第 4 小节 | 霓虹城市屋顶：楼群随底鼓弹跳，窗户随中频亮起，“CLAUDE”霓虹招牌随打击闪烁 |
| 8.6–10.3s | 第 5 小节 | 骑着彗星穿越太空：星流速度跟随贝斯能量，每一次底鼓放出一圈光环 |
| 10.3–12.05s | 第 6 小节 | 合成波网格：三个 Clawd 同步起跳，网格每拍滚动一行，底鼓时线条闪亮 |
| 12.05–13.8s | 第 7 小节 | 贝斯撤出，画面变柔和，Clawd 在云上漂浮；“Claude”按八分音符逐字出现，接着出现“听见音乐的样子 ✻”；最后一次低频击打时闪一下，然后结束 |

主段里 Clawd 每一拍跳起、正好在拍点落地，每次底鼓都会挤压一下身体、镜头也随之震动。
