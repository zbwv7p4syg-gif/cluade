# 给我一个理由忘记 · 铅笔 MV

以 A-Lin《给我一个理由忘记》为背景音乐的 4 分 49 秒动画 MV，字幕是你提供的歌词，规格为 1920×1080、30fps。

- **画法：铅笔素描加水彩**。现在的时间线画成米色纸上的灰色铅笔线稿：排线阴影，雨夜是用铅笔涂暗的天空，雨是被橡皮擦出来的浅色线。只有回忆、城市的灯光和他那件冬天的红外套用水彩上色。铅笔线像手绘动画那样，每秒换 12 次轻微的抖动；最后颜色从晨光里漫开，铺满整座城市。
- **角色**：两个原创人物。"我"是黑色长发、灰色长大衣的女生；"你"是短发、穿红色冬天外套的男生。人物按写实比例画，脸只有眼睛和嘴的几笔。每个部位下面垫一层纸色，前后遮挡才会正确。
- **字幕**：用铅笔手写体逐字写出来，背后是一小块被擦干净的纸。唱到哪里就染成红色，回忆的镜头里染成暖橙色，下面再划一道同色的铅笔线。进度来自 Whisper 测出的每个字的起点（只存时间，不存文字）。
- **字体**：龙藏体（Long Cang，OFL）的子集，改名为 Wangji Hand，许可见 `assets/OFL.txt`。
- **不放进仓库的文件**：歌曲、歌词和成片只放在 `wangji/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `analyze.py` | 分析音乐：节拍、底鼓、频段包络，并用 Whisper 测出每个字的起点 |
| `src/beatmap.js` | `analyze.py` 的输出 |
| `src/timeline.js` | 分镜表：每个镜头的开始时间、镜头函数和场景版本（0 夜晚的城市，1 冬天，2 暴雨之后） |
| `src/sketch.js` | 画法工具：抖动的铅笔线、排线、水彩、纸纹、两个人物、路人、手写字幕 |
| `src/scenes.js` | 40 多个镜头函数，以及逐帧合成（镜头之间淡入淡出） |
| `render.mjs` | 用 Playwright 逐帧渲染，用 ffmpeg 合成音乐，最后检查音轨是否对齐 |

## 分镜

| 时间 | 镜头 |
| --- | --- |
| 0–47s | 雨水顺着窗玻璃往下流，窗外是模糊的彩色灯光，片名被一笔一笔写出来；雨里的整座城市；斑马线上撑伞的人从她身边走过；雨渐渐变小，她放下伞 |
| 47–61s | 她抬头看用铅笔涂灰的天，最后一滴雨落进水洼；回忆变成彩色：他在起雾的咖啡馆窗上画了一个笑脸，她笑了 |
| 61–74s | 深夜空荡的街，每一步都在纸上画出刺耳的声响；她一个人抱着自己，站在大片空白里；城市里是彩色的灯和烟火，她拉下灯绳，自己那扇窗暗了 |
| 74–88s | 人群从两边涌过，又被橡皮一点点擦掉，只剩下她；在朋友中间她笑着；她心里是一颗铅笔画的心，里面在下雨，雨水越积越高 |
| 88–120s | 副歌：她用橡皮擦掉他的画像，线条却自己又画了回来；回忆：雪地里他把红外套披在她身上；她的拇指停在他照片的删除键上方，没有按下；那晚两把伞朝相反的方向走远；她从心口抽出一根红线，越抽越长；他模糊的轮廓慢慢变清晰、变成彩色；一把尺子量着两个人之间的距离；长椅的另一半只剩一圈虚线；她按住胸口，心里是彩色的他 |
| 120–133s | 间奏：窗外的树叶变黄、落光，下起了第一场雪 |
| 133–160s | 她沿着街走，两人以前常去的店里，每一扇橱窗里都还坐着彩色的两个人；雪地里他张开双臂转着圈大笑，她回过头；她推开小屋的门，屋里只有一张椅子、一个杯子；她在门口停住；墙上挂着那件红外套，是屋里唯一的颜色，她把袖子贴在脸上 |
| 160–207s | 冬天里再唱一遍：人群里也下着雪，那张合照想撕又停了手 |
| 207–224s | 暴风雨回来了：大雨和闪电，她站在雨里 |
| 224–259s | 最后一段副歌：她放下橡皮，画像染上了颜色；大雨里，他穿着红外套走进雨中；她把手机贴在胸口，删除键渐渐淡去；她坐在公交站等，身后的季节一轮一轮地换；最后一次按住胸口，颜色从心里漫出来，铺满整页纸 |
| 264–269s | 她用手指在起雾的窗上画了一颗心，与开头他画的笑脸前后呼应 |
| 269–289s | 早晨，颜色漫进整座城市的线稿，鸟飞过，片名再写一遍，淡出 |

## 重新渲染

```bash
cd wangji
pip install librosa faster-whisper
python3 analyze.py /path/to/给我一个理由忘记.mp3                    # -> build/bgm.wav、src/beatmap.js（beatmap.js 已提交，可以跳过）
node render.mjs /path/to/给我一个理由忘记.mp3 --lyrics 你的歌词.lrc   # -> build/给我一个理由忘记_铅笔MV.mp4，约 16 分钟
node render.mjs --stills 20,70.5,134 --lyrics 你的歌词.lrc            # 抽帧检查，输出到 build/stills/
```
