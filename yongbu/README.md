# 永不失联的爱 · 像素 MV

以你提供的音频为背景音乐的 5 分 27 秒像素动画 MV，规格为 1920×1080、30fps。剧情按参考剧情包《给你留一盏灯》来做：阿迟退租前回到两人住过的旧屋，红台灯坏了，他在抽屉里找到小满留下的备用灯泡，才看见自己一直漏掉的那半段日子。"永不失联"落在那一格一直亮着的窗上：每次他下夜班回来，巷子里先亮起来的那一格窗，都是她留给他的。

- **片头**：0.6 秒起，雨夜旧楼上空的片名《永不失联的爱》像灯丝一样逐字闪亮，旁边的信号格在找信号；镜头下摇推近楼里唯一亮着的那一格窗，窗帘上两个人影靠在一起，灯一闪熄灭。12.9 秒音乐起来，片名在整座夜城上空炸开，信号格一格格满上，一颗心跳起来，城里的窗从那一格往外一圈圈亮起来。车灯扫过，进入退租的最后一晚。
- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。工具函数从 `aicuo/` 复制而来。旧屋用同一套坐标反复出现（门在左、窗在右、靠窗书桌、门边铁碟、墙上合照、搁板），先画固有色，再整体乘一层环境光（现实偏冷的深蓝灰，回忆偏暖的杏色，清晨从灰蓝到粉金），台灯的暖光是点阵分档的光圈和光锥。
- **角色**：阿迟短黑发、左边一缕翘发，今夜穿深海蓝外套，回忆里穿靛蓝长袖、袖口一块浅灰补丁；小满齐下巴短发、右边一枚银色发夹，回忆里穿砖红针织衫，出门披灰绿外套、拖灰绿硬壳箱。新加了蹲、踮脚、坐地板、托东西、按胸口、贴玻璃等姿势。特写的手先画在小图上再描一圈轮廓。
- **道具连续**：红台灯（左边一处浅凹、黑色线控开关）、琥珀杯和有缺口的蓝杯、右下角绣黄色弯月的绿格布、挂蓝线和只有黄铜环的两把钥匙。两次开灯（00:38.20、02:44.60）、换完灯泡和最后关灯用的是同一个开关特写机位；04:48.30 最后一个"心"字上，他把包着合照的绿格布按在胸前口袋上。
- **字幕**：文泉驿点阵正黑 16px，按 `.lrc` 的时间逐字浮上来，按估计的演唱进度从月白变成灯光的蜜金，下面一只小灯泡跟着进度往右走。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `yongbu/build/`，这个目录已加入忽略列表。

## 重新渲染

```bash
cd yongbu
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py build/song.mp3 --lyrics build/lyrics.lrc                     # -> build/永不失联的爱_像素MV.mp4
python3 render.py build/song.mp3 --lyrics build/lyrics.lrc --stills 13,38.5,165  # 抽帧检查，输出到 build/stills/
python3 render.py build/song.mp3 --lyrics build/lyrics.lrc --range 0,20          # 只渲染一段带声音的预览
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐。用 `--jobs` 可以改进程数。
