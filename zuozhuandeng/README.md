# 左转灯 · 像素 MV

以《左转灯》为背景音乐的 3 分 17 秒像素动画 MV，字幕是你提供的歌词，规格为 1920×1080、30fps。

- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。天空、光晕、半透明和溶解都用 Bayer 点阵过渡。工具函数从 `xiangni/pix.py` 复制而来，换了角色造型。
- **角色**：两个原创角色。"我"是黑色乱发、穿琥珀色连帽卫衣的男孩，开一辆奶白色的小车；"你"是深棕色马尾、穿青绿色 17 号球衣的女孩。另有一个长小犄角的坏酒瓶、一个小丘比特，都是原创的。
- **主线**：转向灯。片头、字幕和很多镜头里都有一个琥珀色的左转箭头跟着节拍一亮一灭，配着"嗒"字；他一直打着左转灯，却一次次往右转。最后天亮时，在通往她家和通往日出的丁字路口，他往右开走，灯"咔"地灭了。
- **一句一镜**：每一句唱词都有自己的镜头，切点就是 `.lrc` 里这句的时间。重复的副歌每次换一套画面。空行后面超过 5 秒没有歌词的地方，依次用作间奏、天亮的公路和片尾。镜头顺序是按这首歌的 58 句写的，换别的歌词会循环使用。
- **跟着音乐动**：用 ffmpeg 解码音乐，动态规划跟踪节拍（约 66 BPM），再按和声变化定出小节线。片头按小节剪，片名的三个字在拍点上锁定；转向灯、雨刷、篮球、心跳线都踩在拍子上。
- **字幕**：文泉驿点阵正黑 16px，逐字弹出，再按估计的演唱进度从左到右由白变成转向灯的琥珀色；左边一个小箭头跟着拍子闪。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `zuozhuandeng/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `pix.py` | 像素工具：缓动、点阵渐变与光晕、粒子、城市与花草、两个角色的精灵图、文字 |
| `props.py` | 道具：跟着节拍闪的转向灯箭头，小车的侧面、俯视和车尾，手机和聊天界面，霓虹片名，拍立得，湿地面倒影 |
| `sc_verse.py` | 片头、主歌、第一段副歌 |
| `sc_rap.py` | 说唱段 |
| `sc_end.py` | 第二、三段副歌，两段间奏，天亮的结尾和片尾 |
| `scenes.py` | 分镜表：每句歌词对应哪个镜头、用什么转场 |
| `render.py` | 读歌词、分析音乐、排镜头、转场和字幕、分块并行编码、合成音乐 |

## 重新渲染

```bash
cd zuozhuandeng
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py /path/to/左转灯.mp3 --lyrics 你的歌词.lrc                      # -> build/左转灯_像素MV.mp4
python3 render.py /path/to/左转灯.mp3 --lyrics 你的歌词.lrc --stills 8,67,105    # 抽帧检查，输出到 build/stills/
python3 render.py /path/to/左转灯.mp3 --lyrics 你的歌词.lrc --range 0,20         # 只渲染一段带声音的预览
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐。用 `--jobs` 可以改进程数。
