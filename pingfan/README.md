# 平凡的一天 · 像素 MV

以毛不易《平凡的一天》为背景音乐的 4 分 37 秒像素动画 MV，字幕是你提供的歌词，规格为 1920×1080（16:9）、30fps。画法和工具与 `nanguo/` 相同：480×270 的像素画布，导出时最近邻放大 4 倍。

- **故事**：一个小镇上从早到晚的一天。主角穿白 T 恤、胸前有个天蓝色口袋，身边有一只橘猫、一个穿橙色 T 恤的朋友，还有卖菜的阿姨、老爷爷、小孩和路过的姑娘。
- **开头**：分成两个镜头。先是小镇全景从夜里亮到黎明，星星淡去，太阳升起，小火车冒着烟过桥，窗户一扇扇亮起，烟囱开始冒烟，橘猫走过街道，鸟飞过，片名逐字打出；然后是主角卧室，阳光慢慢爬过地板，闹钟走向七点半。
- **重复的副歌**：每唱一遍换一个时间段，第一遍是黄昏，第二遍是夜里，第三遍是第二天金色的早晨。
- **不放进仓库的文件**：歌曲、歌词和成片只放在 `pingfan/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。
- **字体**：Fusion Pixel 12px Proportional SC 的子集，按 OFL 要求改名为 Pingfan Pixel，许可见 `assets/OFL.txt`。

## 重新渲染

```bash
cd pingfan
pip install librosa faster-whisper
python3 analyze.py /path/to/平凡的一天.mp3                    # -> build/bgm.wav、src/beatmap.js（beatmap.js 已提交，可以跳过）
node render.mjs /path/to/平凡的一天.mp3 --lyrics 你的歌词.lrc   # -> build/平凡的一天_像素MV.mp4
node render.mjs --stills 20,70.5,134 --lyrics 你的歌词.lrc     # 抽帧检查，输出到 build/stills/
```
