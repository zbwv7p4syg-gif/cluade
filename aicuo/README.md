# 爱错 · 像素 MV

以《爱错》为背景音乐的 4 分 01 秒像素动画 MV，字幕是你提供的歌词，规格为 1920×1080、30fps。

- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。天空、光晕、烟和溶解都用 Bayer 点阵过渡。工具函数从 `lixiang/` 复制而来，换了角色，去掉了用不上的道具。
- **角色**：都是原创。"他"穿深蓝连帽外套、围冰蓝围巾，像北风一样冷；"她"披黑褐色长发、穿红大衣、别一枚橙黄的叶子发卡，像那片红叶；"北风"是一团冰蓝色的云，有眼睛，会鼓起腮帮子吹气、难过、哭、怒吼；"红叶"是一片心形的叶子，代表她。
- **片头**：黑暗里一片心形红叶落下来，在第一个鼓点被风卷走；满天的叶子飞回来，一格一格拼成片名，片名在小节线上裂开，北风把它吹散成落叶。
- **主线**：第一段主歌是北风和红叶的寓言；副歌换成他和她的故事，雨夜路口、纸飞机、倒转的大钟、"是否重来？"；第二段主歌翻出相册、放映室的银幕背面和碎掉的镜子；最后一段副歌是一场风暴，风停以后他把红叶交给北风，北风轻轻把它托上月亮。片尾天亮了，秃树冒出新芽，片名的裂缝被金色补好。
- **一句一镜**：每句唱词一个镜头，切点就是 `.lrc` 里这句的时间；两段副歌的同一句各用一套不同的画面。片头从 0 秒演到第一句，最后一句后面的空档用作片尾。
- **字幕**：逐字浮上来，按估计的演唱进度从米白变成叶子红，下面一道风里飘着一片小红叶表示进度。括号里的和声用冰蓝色单独排一行，整句都是和声时放在主字幕的位置。唱完后字幕只多停两秒，长间奏里不会一直挂着。
- **跟着音乐动**：用 ffmpeg 解码音乐，动态规划跟踪节拍（约 73 BPM）并定出小节线。片名拼好、裂开，心跳、心电图、闪电、震屏、连砸三次的片名都踩在拍子上。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `aicuo/build/`，这个目录已加入忽略列表。渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `pix.py` | 像素工具：缓动、点阵渐变与光晕、粒子、城市与花草、角色精灵、文字 |
| `props.py` | 通用道具：节拍、点阵贴图、镜头内分段、震屏、烟、火车、钟、片名大字、拍立得、特写的大脸、雨和倒影 |
| `motifs.py` | 这首歌自己的道具：北风精灵、心形红叶、会被吹秃的树、会裂开的大心、纸飞机、捧着的手、雪地小屋、极光、闪电、大钟、镜子、相册、老电视、长椅、灯塔、白鸟 |
| `sc_a.py` | 片头和第一段主歌：红叶拼成的片名、黄昏山坡的大风、被吹落的树叶、逃走的红叶、空荡荡的原野、冬夜的小屋和结冰的湖 |
| `sc_b.py` | 第一段副歌和间奏：雨夜路口、裂开的心和心电图、楼顶的纸飞机、倒转的大钟、"是否重来？"倒数 |
| `sc_c.py` | 第二段主歌和副歌：旧相册和野餐、指缝漏光、放映室和银幕背面、镜子、雨夜狂奔、炸开的像素心、海边白鸟、老电视倒带 |
| `sc_d.py` | 桥段、最后一段副歌和片尾：长椅、手电与萤火、黄昏站台、褪色的照片、风暴、特写、坠落、碎掉的钟、极光、接住和放手、连砸的片名、天亮、金色补好的片名 |
| `scenes.py` | 分镜表：每句歌词对应哪个镜头、用什么转场 |
| `render.py` | 读歌词、分析音乐、排镜头、转场和字幕、分块并行编码、合成音乐 |
| `cover.py` | 竖屏封面：下雪的夜里挂着极光，像素方块拼成的片名中间裂开一道发亮的缝；她穿红大衣站在积雪的秃树下背对着我们，北风缩在半空难过地看着一片心形红叶被吹向她，近处的他伸手去够。画在 270×480 的画布上，放大 4 倍到 1080×1920 |

## 重新渲染

```bash
cd aicuo
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py /path/to/爱错.mp3 --lyrics 你的歌词.lrc                     # -> build/爱错_像素MV.mp4
python3 render.py /path/to/爱错.mp3 --lyrics 你的歌词.lrc --stills 3,60,140   # 抽帧检查，输出到 build/stills/
python3 render.py /path/to/爱错.mp3 --lyrics 你的歌词.lrc --range 0,20        # 只渲染一段带声音的预览
python3 cover.py --lyrics 你的歌词.lrc                                    # -> build/爱错_封面.png，1080×1920 竖屏封面
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐。用 `--jobs` 可以改进程数。
