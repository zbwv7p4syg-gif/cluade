# 噜噜和噜妹儿 · Claude Code 版

这是对抖音短片《噜噜和噜妹儿》的 Claude Code 版复刻：噜噜是橙色的 Clawd，噜妹儿是粉色的 Clawd。

成片：[`build/lulu.mp4`](build/lulu.mp4)，规格为 1920×1080、30fps，时长 16 秒。

**画面和声音全部原创生成，没有使用原片的任何画面或音频。** 分镜结构和剪辑点沿用原片（2.07 / 4.13 / 5.47 / 9.07 / 15.07 秒）。

| 时间 | 镜头 | 内容 | 字幕 |
| --- | --- | --- | --- |
| 0–2.07s | 远景 | 噜妹儿坐在床上，噜噜站在小凳子上背对她做饭 | 噜噜噜噜噜噜 |
| 2.07–4.13s | 特写 | 噜妹儿眼泪汪汪，泪水流下来（背景虚化） | 噜噜噜噜噜噜 |
| 4.13–5.47s | 中景 | 噜噜从背影转过身 | 嗯？ |
| 5.47–9.07s | 远景 | 噜噜擦手、跳下凳子，一路走到床边 | 怎么了 |
| 9.07–15.07s | 双人镜头 | 噜妹儿张开手扑进噜噜怀里，两人贴脸拥抱，冒出爱心；镜头慢慢推近，背景反向移动，营造环绕的感觉 | 我想你了 / 哈哈哈我也想你呀 |
| 15.07–16s | 片尾 | “噜噜和噜妹儿 · Claude Code 版” | |

## 怎么做的

| 文件 | 作用 |
| --- | --- |
| `src/score.js` | 时间线：镜头、台词（逐字拆成音节）、脚步、眼泪、拥抱、配乐 |
| `src/audio.js` | 用 Web Audio 合成声音。角色的“噜噜”语音用锯齿波加两个共振峰滤波器模拟元音，噜妹儿约 540Hz，噜噜约 300Hz，哭腔带颤音；另有八音盒、钢片琴、铺底、锅里的滋滋声、脚步、泪滴和拥抱音效 |
| `src/chars.js` | 两个角色：Clawd 的造型，加上配色、背影、泪眼、说话口型和服饰（噜妹儿的荷叶边帽和草莓裙，噜噜的斜挎包和头顶小橘子） |
| `src/visuals.js` | 房间场景和各镜头的机位；特写时单独虚化背景层 |
| `render.mjs` | 逐帧渲染，并用 ffmpeg 合成 MP4 |

角色的嘴型和字幕，与合成语音读取的是同一份音节表，所以口型和声音是同步的。

```bash
cd lulu && node render.mjs
```
