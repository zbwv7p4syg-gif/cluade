# 小宇 · 像素 MV

以张震岳《小宇》为背景音乐的 3 分 44 秒像素动画 MV，字幕是你提供的歌词，规格为 1920×1080、30fps。

- **像素画法**：与 `nanguo/` 相同，所有画面都画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。
- **角色**：两个原创角色。"我"是棕色乱发、穿黄 T 恤和牛仔裤的男孩；"你"是黑色长发、别一朵白花、穿浅蓝连衣裙的女孩。男孩还会变成两样东西：一朵带着他那撮棕色头发的小云，和一只帆上画着红心的小木船。
- **一句一镜**：每一句唱词都有自己的镜头，切点就是 `.lrc` 里这句的时间。故事发生在一个海边小镇：白天的海边相遇，雨落在她心里那片心形的土地上，夜里的心形湖和灯塔，间奏里的吉他、孔明灯和烟火，最后他在暮色里划船离开。
- **字幕**：像游戏对话框一样先逐字打出，再随演唱进度从左到右变亮。进度来自 Whisper 测出的每个字的起点（只存时间，不存文字）。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `xiaoyu/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `analyze.py` | 分析音乐：拟合节拍网格，检测底鼓，导出 30fps 频段包络，并用 Whisper 测出每个字的起点 |
| `src/beatmap.js` | `analyze.py` 的输出 |
| `src/timeline.js` | 分镜表：每个镜头的开始时间和用哪个镜头函数 |
| `src/pixel.js` | 像素工具和两个角色的精灵图（从 `nanguo/` 复制后改了角色） |
| `src/scenes.js` | 35 个镜头函数，小云、小船、灯塔、遮阳帽等道具，以及逐帧合成 |
| `render.mjs` | 用 Playwright 逐帧渲染，用 ffmpeg 放大并合成音乐，最后检查音轨是否对齐 |
| `assets/xiaoyu-pixel-subset.woff2` | 像素字体：Fusion Pixel 12px Proportional SC 的子集，按 OFL 要求改名为 Xiaoyu Pixel。许可见 `assets/OFL.txt` |

| 176.3–191.9s | 周一到周日，每天带不同的东西出现在她家门口；他合上那本大书，牵起她的手；夕阳下的码头，两人手牵手 |

| 207.35–224.4s | 夜里的海，地平线上一盏小小的船灯，小云飘过月亮，她站在码头上，片名再次出现，淡出 |

## 重新渲染

```bash
cd xiaoyu
pip install librosa faster-whisper
python3 analyze.py /path/to/小宇.mp3                         # -> build/bgm.wav、src/beatmap.js（beatmap.js 已提交，可以跳过）
node render.mjs /path/to/小宇.mp3 --lyrics 你的歌词.lrc        # -> build/小宇_像素MV.mp4
node render.mjs --stills 20,70.5,134 --lyrics 你的歌词.lrc     # 抽帧检查，输出到 build/stills/
```
