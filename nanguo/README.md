# 我不难过 · 像素 MV

以孙燕姿《我不难过》为背景音乐的 4 分 58 秒像素动画 MV，字幕是你提供的歌词，规格为 1920×1080、30fps。

- **像素画法**：所有画面都画在 480×270 的画布上，只用整像素的方块，渐变用 4×4 拜耳抖动。导出时由 ffmpeg 用最近邻放大 4 倍，每个像素都是清晰的 4×4 方块。
- **角色**：三个原创角色。"我"是黑色短发、系红围巾、别红发夹的女孩；"你"是穿蓝色连帽衫的男孩；"她"是浅棕长发、戴白花、穿粉色开衫的女孩。人物先在 30×37 的小精灵图上画好，自动描一圈深色轮廓，再按整数倍放大。
- **一句一镜**：每一句唱词都有自己的镜头，切点就是 `.lrc` 里这句的时间。重复的段落换一种色调重讲一遍：第一遍是雨夜，第二遍是黄昏的回忆（画面四角加了旧照片的圆角暗边），最后一遍是天快亮的时候，结尾是日出。
- **字幕**：像游戏对话框一样先逐字打出，再随演唱进度从左到右变亮。进度来自 Whisper 测出的每个字的起点（只存时间，不存文字）。字幕旁的 ♪ 随拍子跳动。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，受版权保护，只放在 `nanguo/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `analyze.py` | 分析音乐：拟合节拍网格，检测底鼓，导出 30fps 频段包络，并用 Whisper 测出每个字的起点 |
| `src/beatmap.js` | `analyze.py` 的输出 |
| `src/timeline.js` | 分镜表：每个镜头的开始时间、用哪个镜头函数、用哪种色调 |
| `src/pixel.js` | 像素工具：抖动渐变、像素图形、三个角色的精灵图、雨伞和气泡等道具、跟唱字幕框、抖动转场 |
| `src/scenes.js` | 40 多个镜头函数，以及逐帧合成 |
| `render.mjs` | 用 Playwright 逐帧渲染 480×270 的画面，用 ffmpeg 最近邻放大到 1920×1080 并合成音乐，最后检查音轨是否对齐 |
| `assets/nanguo-pixel-subset.woff2` | 像素字体：Fusion Pixel 12px Proportional SC 的子集，按 OFL 要求改名为 Nanguo Pixel。许可见 `assets/OFL.txt` |

## 重新渲染

```bash
cd nanguo
pip install librosa faster-whisper
python3 analyze.py /path/to/我不难过.mp3                       # -> build/bgm.wav、src/beatmap.js（beatmap.js 已提交，可以跳过）
node render.mjs /path/to/我不难过.mp3 --lyrics 你的歌词.lrc       # -> build/我不难过_像素MV.mp4
node render.mjs --stills 20,70.5,134 --lyrics 你的歌词.lrc        # 抽帧检查，输出到 build/stills/
node render.mjs /path/to/我不难过.mp3 --lyrics 你的歌词.lrc --from 100 --to 115   # 只渲染一段预览
```

`.lrc` 的格式是每行 `[分:秒.百分秒]字幕`。镜头的切点按这首歌的原版时间写在 `src/timeline.js` 里。如果你的 `.lrc` 时间不同，字幕会跟着你的文件走，镜头不会。新字幕里如果有字体子集没有的字，需要重新生成字体子集。
