# 人死后会去哪 · 纸片拼贴动画

成片：[`build/afterlife.mp4`](build/afterlife.mp4)，规格为 1920×1080、30fps、H.264 + AAC，时长 52.8 秒。

画面、音乐和音效全部由 JavaScript 生成：画面用 Canvas 绘制，声音用 Web Audio 合成，没有使用任何图片、录音或采样。

## 学到的风格

参考的是一段“纸片拼贴 + 小太阳角色”的短片（“what do you love?”），整理出以下几个要点，并逐一实现：

| 参考片的特点 | 这里的实现（`src/paper.js`） |
| --- | --- |
| 所有形状都像彩纸剪出来的，四周有一圈**白色撕纸边** | `cut()`：先把多边形轮廓细分并加入随机抖动，画出一圈奶白色的毛边，再填上彩色纸片 |
| 纸面有**蜡笔笔触和纸张纹理** | 预先生成一张蜡笔斜线纹理，裁剪到每块纸片内部叠加；整帧最后再用 `multiply` 叠一层纸纤维颗粒 |
| **定格动画式的抖动** | 撕纸边的随机种子每秒更换 8 次（`BOIL`），轮廓会轻轻“呼吸”，就像逐格重拍的剪纸 |
| **手写字**逐字写出，笔跟着字走 | `hand()`：用站酷快乐体逐字揭开，返回当前笔尖位置，手臂和铅笔跟随笔尖 |
| 叙事结构：**写下问题 → 折纸飞机 → 飞向夜空 → 小太阳接住 → 快切一连串答案** | 沿用这一结构，把问题换成“人死后，会去哪里？” |
| 答案段落：**纯色背景 + 放射短线 + 道具 + 角色 + 手写标签**，按节拍快切 | 8 个答案，每个 2 拍（1.2 秒），硬切，放射线随节拍脉动 |

## 分镜（100 BPM，每拍 0.6 秒 = 18 帧，全部在小节线上切）

| 时间 | 镜头 | 内容 |
| --- | --- | --- |
| 0–4.8s | 夜景 | 撕纸夜空、月亮、小镇、小太阳；紫色房子里亮着一扇窗，镜头推近 |
| 4.8–9.6s | 窗口 | 女孩捧着奶奶的照片，掉下一滴眼泪；随后抬头望向夜空，冒出一个“？” |
| 9.6–14.4s | 书桌 | 在笔记本上一笔一笔写下“人死后，会去哪里？”（每个字都有铅笔沙沙声） |
| 14.4–16.8s | 书桌 | 三次对折，把纸折成纸飞机（每折一次都有纸张声） |
| 16.8–19.2s | 窗口 | 把纸飞机扔出窗外 |

| 26.4–36s | 答案 | 变成天上的星星 / 回到大海 / 长成一棵大树 / 住进故事里 / 留在歌里 / 藏在饺子的味道里 / 变成一阵风 / 住在你心里 |
| 36–38.4s | 夜空 | 小太阳写好回信，折成纸飞机扔回去 |

| 43.2–48s | 信纸 | 回信逐字出现：“会去所有 / 还记得他们的地方。” 落款是一个小太阳 |
| 48–52.8s | 夜景 | 女孩笑了，月亮旁亮起一颗新的星星，片名“人死后，会去哪里？ / 写给每一个想念的人” |

## 文件

| 文件 | 作用 |
| --- | --- |
| `src/score.js` | **唯一的时间轴**：镜头、和弦、旋律、每一笔写字、每一次折纸、每一声“叮” |
| `src/paper.js` | 剪纸工具：撕纸边、蜡笔纹理、纸张颗粒、定格抖动、手写字 |
| `src/chars.js` | 角色：Claude 小太阳、女孩、奶奶的照片、纸飞机、横线信纸 |
| `src/visuals.js` | 13 个镜头的画面，以及 8 个答案的道具 |
| `src/audio.js` | 合成配乐与音效：尤克里里式拨弦、八音盒、口哨旋律、贝斯、响指和沙锤、钢片琴，以及铅笔、折纸、飞行、弹出等纸张音效 |
| `subset.py` | 从 `src/` 里提取用到的汉字，生成站酷快乐体子集 |
| `render.mjs` | 用 Playwright 逐帧渲染，再由 ffmpeg 合成 MP4 |
| `assets/` | 站酷快乐体子集（SIL Open Font License，许可证见 `OFL-ZCOOLKuaiLe.txt`） |

## 重新生成

```bash
cd afterlife
python3 subset.py ZCOOLKuaiLe-Regular.ttf   # 只有改了文字才需要
node render.mjs                             # -> build/afterlife.mp4
node render.mjs --stills 6,23.5,30          # 导出单帧，便于检查
```

也可以直接在浏览器里打开 `index.html`，点“▶ 播放”，页面会先实时合成声音再开始播放。
