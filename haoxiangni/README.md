# 我好想你 · 像素 MV

以苏打绿《我好想你》为背景音乐的 5 分 27 秒像素动画 MV，字幕是你提供的歌词，规格为 1920×1080（16:9）、30fps、H.264 + AAC。

- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。天空、光晕、明暗、半透明和镜头之间的溶解都用 Bayer 点阵过渡。
- **角色**：两个原创角色。"我"是黑色短发、穿米白毛衣的人；"你"是栗色长发、穿鹅黄外套、围一条红围巾的人。那条红围巾是全片的线索：片头围在"我"脖子上，主歌里挂在卧室的衣帽架上，间奏的回忆里是她亲手给围上的，片尾又被取下来围好。
- **一句一镜**：每一句唱词都有自己的镜头，切点就是 `.lrc` 里这句的时间；两段主歌、三段副歌的歌词相同，画面各不重复。空行后面超过 5 秒没有歌词的地方，依次用作间奏（四段回忆）和片尾。
- **跟着音乐动**：用 ffmpeg 解码音乐，算出每一帧的音量；用动态规划跟踪节拍，再按和声变化最大的相位定出小节线。片名在音乐进来的那条小节线（12.69 秒）上炸开，卧室的三次推近、间奏的烟花、胸口的心跳都落在拍点和小节线上。
- **字幕**：文泉驿点阵正黑 16px，逐字浮上来，按演唱进度从米白变成粉红，下面一颗小红心跟着进度走、在拍点上跳；副歌里的"我好想你"用两倍大的字。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `haoxiangni/build/`，这个目录已加入忽略列表。仓库里不保存歌词，渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `pix.py` | 像素工具：缓动、点阵渐变与光晕、粒子、城市与树、两个角色的精灵图、文字 |
| `props.py` | 道具：点阵明暗的灯光、推拉镜头、对话泡泡、心、俯视的卧室和窗、火车、拍立得、特写的大脸、雨和倒影 |
| `sc_a.py` | 片头和第一段主歌 |
| `sc_b.py` | 第一段副歌和间奏的四段回忆 |
| `sc_c.py` | 第二段主歌和第二段副歌 |
| `sc_d.py` | 最后一段副歌和片尾 |
| `scenes.py` | 分镜表：每句歌词对应哪个镜头、用什么转场 |
| `render.py` | 读歌词、分析音乐、排镜头、转场和字幕、分块并行编码、合成音乐 |

## 重新渲染

```bash
cd haoxiangni
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py /path/to/我好想你.mp3 --lyrics 你的歌词.lrc                      # -> build/我好想你_像素MV.mp4
python3 render.py /path/to/我好想你.mp3 --lyrics 你的歌词.lrc --stills 20,90,290   # 抽帧检查，输出到 build/stills/
python3 render.py /path/to/我好想你.mp3 --lyrics 你的歌词.lrc --range 0,40         # 只渲染一段带声音的预览
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐，在 4 核机器上大约四分钟。用 `--jobs` 可以改进程数，`--crf`、`--preset` 可以改 x264 的画质和速度。
