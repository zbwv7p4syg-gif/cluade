# Claude Code 电音派对

成片：[`build/party.mp4`](build/party.mp4)，规格为 1920×1080、30fps、H.264 + AAC，时长 60 秒。

画面和音乐全部用 JavaScript 生成，没有任何音频文件或素材。DJ 是 Clawd（Claude Code 的吉祥物），戴着耳机站在打碟台后面。

| 文件 | 作用 |
| --- | --- |
| `src/score.js` | **唯一的时间轴**：128 BPM、F 小调、32 小节，列出每一个鼓点、音符和特效事件 |
| `src/audio.js` | 用 Web Audio API（OfflineAudioContext）合成全部电音：失真底鼓、侧链抽吸的 Supersaw、Reese 贝斯、军鼓滚奏、噪声上升、冲击音、玻璃碎裂声、人群欢呼 |
| `src/clawd.js` | Clawd 角色（戴 DJ 耳机） |
| `src/visuals.js` | 按同一份时间轴绘制画面：终端、裂纹、碎片、LED 大屏、摇头灯、激光、音箱、人群、CO₂、火焰、彩带 |
| `render.mjs` | 逐帧渲染，用 ffmpeg 合成 MP4，最后自动做卡点检测 |

```bash
cd party
node render.mjs                    # 生成 build/music.wav 和 build/party.mp4，并输出卡点报告
DETAIL=1 node render.mjs --check   # 只做卡点检测，并列出误差超过 5ms 的鼓点
```

## 结构：突破 → 平静 → 燃

| 时间 | 段落 | 内容 |
| --- | --- | --- |
| 0–7.5s | 墙后 | 底鼓像是隔着墙传来（音频经过 280Hz 低通滤波）。Claude Code 终端里敲下“开一场电音派对，我来当 DJ”，音响、灯光、人群依次就绪，接着提示“墙太厚了”。屏幕随节拍出现裂纹 |
| 7.5s | **突破** | 终端在强拍上碎成碎片，滤波器瞬间全开，出现“突破！”，派对现场正式亮相 |
| 7.5–15s | Groove | House 节奏，全场跟着拍子点头，LED 屏显示 CLAUDE CODE 和均衡器 |
| 15–22.5s | **平静** | 鼓声全部撤掉，只剩 Pad 和钢琴。Clawd 闭眼摇摆，观众举起手机灯光：“节奏慢下来……”“举起你的光” |
| 22.5–29.5s | 蓄力 | 军鼓从四分音符加速到三十二分音符，噪声和音高一起上升，LED 显示“酝酿中 0→100%”。“全场，蹲下——”时人群逐渐蹲低，接着倒数 3、2、1 |
| 29.5–30s | 静默一拍 | 全黑，只剩 Clawd 发光的星星眼 |
| 30–45s | **燃！** | Drop。“跳！！”全场每一拍都起跳，落地正好踩在底鼓上。激光按拍切换，拍手声对应频闪，还有 CO₂ 喷射和彩带炮 |
| 45–56s | 更燃 | 加入火焰，旋律高八度。Clawd 跳下台在人群里冲浪，打碟台屏幕显示“⏵⏵ 自动模式已开启” |
| 56–60s | 终 | 最后一击，出现片名。终端输入 `/exit`，回应是“派对不会结束的～” |

## 卡点

- **同一份时间表。** 音乐和画面读的是同一份 `score.js`，底鼓发声的采样点，就是人群落地、灯光切换、屏幕抖动的时刻。
- **按最近帧显示。** 128 BPM 下一拍是 14.06 帧，不是整数，所以每个节拍事件都显示在离它最近的那一帧上，画面误差不超过半帧（16.7ms）。
- **成片实测。** 渲染器会把成片 MP4 里的音频解码出来，检测每一个底鼓的起音位置并与乐谱比对；检测器本身的延迟，先用单独渲染的底鼓校准扣除。最近一次结果：
  - 99 个底鼓的中位误差为 0.6ms，96 个在 ±10ms 以内，最大误差 10.8ms；
  - 剩下的小偏差来自同一时刻叠在一起的其他声音，例如拍手声触发压缩器、滚奏抬高了背景电平，并不是发声时刻不准。
