# 理想三旬 · 像素 MV

以《理想三旬》为背景音乐的 3 分 33 秒像素动画 MV，字幕是你提供的歌词，规格为 1920×1080、30fps。

- **像素画法**：所有画面都用 Pillow 画在 480×270 的画布上，导出时由 ffmpeg 用最近邻放大 4 倍。天空、光晕、烟和溶解都用 Bayer 点阵过渡。工具函数从 `cengjing/` 复制而来，换了角色和道具。
- **角色**：都是原创。"他"是黑色乱发、围芥末黄围巾、穿橄榄绿外套的年轻人，另有小时候（红白条纹衫）和老了以后（灰白头发、棕色开衫，还是那条黄围巾）的样子；"她"是回忆里的人，浅蓝裙子、黄发卡；一只小黑猫代表"孤独"，从夜车上出现以后一直跟着他，副歌里总在睡觉。
- **主线**：旧铁皮火车。它往南开，穿过黄昏的原野、海上的长桥，开上夜空和鲸鱼同游，在海边的铁轨尽头停下，最后停在原野里爬满青苔。字幕下面也有一段小铁轨，一辆小火车跟着演唱进度往右开。
- **一句一镜**：每句唱词一个镜头，切点就是 `.lrc` 里这句的时间；两段副歌的同一句各用一套不同的画面。片头横跨前两句，超过 5 秒没有歌词的地方用作间奏和片尾。
- **跟着音乐动**：用 ffmpeg 解码音乐，动态规划跟踪节拍（约 50 BPM）。咳嗽、断弦、踩碎枯叶、钟摆摆到两头、眼泪落地、火漆裂开、鸟群起飞、举起手机的光都踩在拍子上。
- **不放进仓库的文件**：歌曲、歌词和成片都是用户的文件，只放在 `lixiang/build/`，这个目录已加入忽略列表。渲染时用 `--lyrics` 读入你自己的 `.lrc`。

| 文件 | 作用 |
| --- | --- |
| `pix.py` | 像素工具：缓动、点阵渐变与光晕、粒子、城市与花草、角色精灵（含小孩、老人、朋友们和小黑猫）、文字 |
| `props.py` | 道具：旧铁皮火车、30 路公交、收音机、卡带、吉他、钟、烟、片名大字、特写的大脸、拍立得和调色 |
| `sc_a.py` | 片头和第一段主歌：雨后街口的片名、往南开的火车、收音机、咳嗽、金色田野、断弦、窗口里戴耳机的小孩、飞转的钟、卡带、枯叶；间奏的海上长桥和夜车 |
| `sc_b.py` | 第一段副歌和间奏：无名站长椅上的四季、天亮的站台、大钟摆、楼顶弹唱、眼泪碎屏、走不到的灯火；开上夜空的火车、云海里的鲸、巨大的月亮 |
| `sc_c.py` | 第二段主歌：大排档、灰色人潮、篝火散场、地下站台、成长的路牌、醒来、干裂的土地、落光的花树、弄脏的诗、裂开的火漆、风里的白鸟 |
| `sc_d.py` | 第二段副歌、间奏和结尾：海边摇椅、纸船、旋转木马、广场弹唱、水洼倒影、铁轨尽头的日出；旧胶片、照片、回家的路；小屋里的热茶、窗台、烛光、合上的本子、晨光、爬满青苔的火车和片名 |
| `scenes.py` | 分镜表：每句歌词对应哪个镜头、用什么转场 |
| `render.py` | 读歌词、分析音乐、排镜头、转场和字幕、分块并行编码、合成音乐 |
| `cover.py` | 竖屏封面：雨后的黄昏，太阳沉进海里，旧铁皮火车亮着窗从海上的长桥开过；站台的积水映着晚霞，他背着吉他、黄围巾被风吹起，和小黑猫背对着我们看火车开远。片名分两行落在天上，下面一段小铁轨上跑着小火车。画在 270×480 的画布上，放大 4 倍到 1080×1920 |

## 重新渲染

```bash
cd lixiang
apt install ffmpeg fonts-wqy-zenhei   # 需要 ffmpeg 和文泉驿正黑（用到里面的点阵字形）
pip install pillow numpy
python3 render.py /path/to/理想三旬.mp3 --lyrics 你的歌词.lrc                     # -> build/理想三旬_像素MV.mp4
python3 render.py /path/to/理想三旬.mp3 --lyrics 你的歌词.lrc --stills 3,60,140   # 抽帧检查，输出到 build/stills/
python3 render.py /path/to/理想三旬.mp3 --lyrics 你的歌词.lrc --range 0,20        # 只渲染一段带声音的预览
python3 cover.py --lyrics 你的歌词.lrc                                        # -> build/理想三旬_封面.png，1080×1920 竖屏封面
```

默认用 4 个进程，各渲染一段连续的帧，最后不重新编码直接拼接，再合成音乐。用 `--jobs` 可以改进程数。
